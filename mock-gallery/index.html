6 · Alpha scope

pick one

What must the first Waydroid build actually do?

Waydroid reality check (for the alpha): it's an x86_64 Android container, so we build only that ABI and the native geometry lib. Filament needs GLES 3.2 (or Vulkan); Waydroid's renderer (gfxstream / Mesa) may expose less, so the plan includes a capability probe that falls back to a Compose-drawn mesh preview if the driver is too old. Also: this machine currently has only adb — no JDK, SDK or NDK — so the first step of the alpha is toolchain setup.
